# Python & Flask Projects

A collection of projects built while learning Python, SQL, and Flask.

## Projects

- [Order Management System](./flask_app) — Flask + SQLite app for managing food orders (add, complete, delete).
- [Login & Authentication System](./login_app) — Flask + SQLite app with user registration, login, and session-based auth.
- [Notes App](./notes_app) — Flask + SQLite app for creating and deleting simple notes.
- [OTP Verification Demo](./otp_project) — Flask app demonstrating OTP generation and verification using sessions.

## Practice Scripts

Smaller standalone scripts written while learning core Python concepts:

- `calculator.py` — basic calculator
- `bmi_calculator.py` — BMI calculator
- `budget_app.py` — personal budget tracker (SQLite)
- `contacts.py` — contact book (SQLite)
- `currency_converter` — currency conversion tool
- `expenses.py` — expense tracker (SQLite)
- `face_detect.py` / `face_recognition.py` — OpenCV face detection/recognition experiments
- `grade.py` — grade calculator
- `guess_game.py` — number guessing game
- `mail.py` / `automatedemail.py` — email automation scripts
- `online_order.py` / `orders.py` — console-based order handling scripts (early precursor to the Flask order system)
- `otp_generator` — OTP generation script
- `quizz.py` — quiz game
- `random_joke.py` — random joke generator
- `word_frequency.py` — word frequency counter

## Setup

Most projects need Flask installed:

```
pip install flask
```

Each project folder has its own README with specific run instructions.
