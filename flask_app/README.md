# Order Management System

A simple Flask + SQLite web app for managing food orders — add new orders, mark them complete, and delete them.

## Features

- Add a new order (item + quantity)
- View all orders with their status (pending / completed)
- Mark an order as completed
- Delete an order

## Built with

- Python, Flask
- SQLite3

## Run locally

```
pip install flask
python app.py
```

Then open http://127.0.0.1:5000 in your browser.
